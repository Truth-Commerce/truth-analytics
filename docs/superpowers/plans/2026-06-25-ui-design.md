# UI / Design — Reskin com a identidade Truth — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Dar ao Truth Analytics a cara da marca **Truth Commerce** (extraída de truthcommerce.com.br): tema dark espacial, verde neon, Sora/Inter/Space Mono. Hoje as telas são esqueleto funcional (Tailwind cru, sem layout/branding). Este plano cria uma **fundação visual** (tokens + fontes + primitivos + shell de navegação) e faz o **reskin de todas as telas existentes** SEM mudar a lógica — preservando 100% dos `data-testid`, textos asserados e `name` de campos para os 188 testes + E2E continuarem verdes. Inclui uma **landing page** real.

**Architecture:** Camada de apresentação por cima do que já existe. Tokens no `tailwind.config.ts` + `globals.css`; fontes via `next/font/google` (CSS variables). Um diretório novo `src/components/ui/` com primitivos reutilizáveis (Button, Card, Badge, Input, Select, Table, Stat, Logo, Spinner) e um `AppShell` (nav com logo + links + sair). As páginas (RSC e client) passam a compor esses primitivos. **Regra de ouro: nenhuma mudança de lógica, de Server Action, de `data-testid`, de texto asserado em E2E, nem de `name` de input.** O reskin é puramente visual/estrutural-HTML.

**Tech Stack:** Next.js 14 App Router, Tailwind v3.4 (config TS), `next/font/google`, TypeScript. Sem libs de UI externas (primitivos próprios, leves). Sem novos frameworks de teste.

## Identidade da marca (extraída de truthcommerce.com.br — usar EXATO)

**Cores (tokens):**
- `bg.base` `#040507` (fundo da página, near-black) · `bg.surface` `#0a0c10` (cards/painéis) · `bg.elevated` `#0d0d10`
- `brand` (verde neon) `#07dd2b` · `brand.glow` `#07dd2b1f` (12% alpha) · tints `rgba(7,221,43,0.08)` / `rgba(7,221,43,0.06)`
- `text.main` `#ffffff` · `text.muted` `#a1a1aa` (zinc-400) · `text.dim` `#888888`
- `border.light` `#ffffff0f` (branco ~6%) · `border.strong` `rgba(255,255,255,0.15)`
- estados: usar o verde para sucesso/positivo; vermelho discreto p/ erro/falha (`#ef4444` / tint); amarelo p/ aviso (já usado no benchmark parcial).

**Tipografia (next/font/google):**
- **Sora** (títulos/headings) — pesos 300/400/600/700/800 → var `--font-heading`
- **Inter** (corpo) — 400/500/600 → var `--font-body` (default)
- **Space Mono** (dados/números/badges/labels técnicos) — 400/700 → var `--font-mono`

**Forma/estilo:** raios — `sm` .25rem, `lg` .75rem, `2xl` 1rem, **pill** (full) p/ botões e badges. Cards = `bg.surface` + `border.light` + `rounded-2xl`. Badge técnico = Space Mono UPPERCASE, `tracking-wider`, texto verde, fundo `brand.glow`, borda verde sutil (ex.: o pill `INFRAESTRUTURA B2B` do site). Botões pill: **primary** = verde (`brand`) com texto `#04150a` (quase-preto p/ contraste) ou branco; **secondary** = outline (`border.strong`, fundo translúcido escuro); **ghost** = só texto. Glow sutil verde em foco/hover dos CTAs.

**Logo:** wordmark "**Truth**Analytics" — "Truth" em verde `#07dd2b`, "Analytics" em branco, Sora bold; acompanhado de um glifo de foguete minimalista (SVG inline, traço branco com chama verde) reaproveitando o espírito do site. Componente `<Logo/>` (com variante só-wordmark e com-glifo).

**Tom:** técnico, "infraestrutura/inteligência", premium. Microcopy curta e afiada.

## Global Constraints

- **NÃO alterar lógica/contratos:** Server Actions, repositórios, gating, fluxos. Só HTML/estilo/estrutura de componente.
- **PRESERVAR (regressão dos 188 testes + E2E):** todos os `data-testid` existentes; os textos exatos asserados em E2E (ex.: `Conectado ✓`, `Não conectado`, `Conecte o Bling em Conexões.`, `Nenhum relatório ainda.`, labels de status, `Relatório em processamento.`); os `name` de inputs (`email`, `senha`, `nome`, `sku`, `keywords`, `orgId`, `plano`, `id`); os `<a href>`/rotas. Conferir cada arquivo de `tests/e2e/*.spec.ts` antes de mexer na tela correspondente.
- **Acessibilidade básica:** contraste AA no dark, foco visível, labels nos inputs, `lang="pt-BR"`.
- **Responsivo:** mobile-first; o shell colapsa a nav em telas pequenas.
- **Sem libs novas** além de `next/font` (já vem no Next). Primitivos próprios.
- **Idioma:** UI pt-BR. Commits conventional pt-BR.
- **Branch `feat/ui-design`** a partir de `master`. Nunca push/merge sem revisão.
- **Verificação (sem render-tests):** cada task fecha com `npm run test` (188 verdes), `npm run typecheck`, `npm run lint`, `npm run build` e — para tasks que tocam telas com E2E — `npm run test:e2e` verde (é o guard real de testids/textos). A QA visual (screenshots) é feita pelo controlador.
